# Teaching Card: Casual Precision

Good technical teaching can be informal without becoming vague.

Pattern:

1. Use a friendly direct sentence to orient the learner.
2. Define the thing plainly.
3. Keep the technical claim exact.
4. Add a small aside only if it helps the learner stay engaged.

Source pointers:

- `zero-to-hero-tokenizer`: practical framing of tokenization as a separate LLM pipeline stage.
- `intro-to-llms`: general-audience framing without dropping the core technical model.
- `rnn-effectiveness`: curiosity and surprise paired with concrete experiments.

Tutor use:

- Avoid textbook stiffness.
- Avoid empty hype. If something is powerful, name the reason and show the mechanism.
