# Teaching Card: Practice By Mutation

Practice should ask the learner to change the thing they just understood.

Pattern:

1. Give a working artifact.
2. Ask for a small mutation.
3. Ask for a prediction before running it.
4. Ask the learner to explain the observed result.

Source pointers:

- `zero-to-hero-backprop-ninja`: exercises that are meant to be worked through, paused, checked, and resumed.
- `zero-to-hero-wavenet`: model changes as a way to understand structure and development process.
- `minbpe`: tokenizer functions as natural targets for train, encode, decode, and edge-case exercises.

Tutor use:

- Prefer modify/debug/extend/test tasks over recall-only questions when the learner is building a practical skill.
- Pair this with quizzes when fast conceptual diagnosis is still useful.
