# Teaching Card: Build The Smallest Real Thing

Use a tiny but working artifact before expanding into the full system.

Pattern:

1. Start with a narrow concrete object.
2. Make it run or produce visible output.
3. Inspect one behavior carefully.
4. Add the next piece only when the learner has a reason to want it.

Source pointers:

- `zero-to-hero-micrograd`, early setup: scalar values before a neural net library.
- `zero-to-hero-makemore-bigram`, early setup: a character-level bigram model before larger language models.
- `llm101n`, syllabus: bigram model before micrograd, attention, transformer, tokenization, and systems work.
- `microgpt`: the full algorithmic content compressed into a tiny dependency-free system.

Tutor use:

- Helpful for any technical tutorial, not just ML.
- Translate the pattern to the subject: smallest parser, smallest query, smallest UI state, smallest proof, smallest experiment.
