# Teaching Card: Make State Visible

When a mechanism feels abstract, expose the state that changes.

Pattern:

1. Show the input or starting state.
2. Name the operation.
3. Show the output, intermediate value, or diagnostic signal.
4. Read the artifact out loud in prose.

Source pointers:

- `zero-to-hero-makemore-activations`: activation and gradient statistics as diagnostics.
- `zero-to-hero-gpt`: tensor shapes and attention internals.
- `recipe-training-nn`: visualizations and defensive inspection during training.

Tutor use:

- Use tables, code output, diffs, diagrams, logs, tests, or screenshots.
- Prefer one visible state transition over a paragraph that merely says something is important.
